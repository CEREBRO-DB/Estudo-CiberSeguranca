Documentação Técnica CÉREBRO-V3

O CÉREBRO-V3 é um ecossistema avançado de auditoria de segurança cibernética, focado em automação de reconhecimento, análise de vulnerabilidades e defesa proativa.

Versões e Ferramentas Usadas

  • Linguagem: Python 3.10+
  • Interface: Streamlit 1.32.0
  • Reconhecimento: Nmap (Network Mapper) via python-nmap
  • Inteligência: GitHub API v3
  • Persistência: JSON (NoSQL-style local database)

🤖 Os Agentes do Ecossistema

🛰️ Orion (Reconhecimento)

Responsável pelo mapeamento de rede. Executa scans de portas, detecção de SO e identificação de serviços (Scripts NSE).

💣 Vektor (Exploração)

Cruza vulnerabilidades encontradas com exploits reais do GitHub e Exploit-DB. Focado em prova de conceito (PoC).

🛡️ Aegis (Defesa)

Gera protocolos de remediação. Transforma uma falha técnica em um plano de ação (Hardening) para o administrador.

🧠 BrainSync (Sincronização)

O "coração" do sistema. Busca novas ameaças via API e alimenta os outros agentes em tempo real.

🔗 Integrações e Base de Dados

O sistema utiliza um modelo de Inteligência Síncrona:

  • GitHub API: Busca dinâmica de CVEs e exploits usando GITHUB_TOKEN.
  • intelligence_core.json: Banco de dados local que armazena o histórico de ameaças, evitando requisições desnecessárias e permitindo uso offline.
  • Nmap NSE: Integração com a biblioteca de scripts do Nmap para auditoria profunda de protocolos.

📖 Manual de Instruções

  1. Configuração: Insira seu GITHUB_TOKEN no arquivo .env.
  2. Sincronização: Clique em "Sincronizar Ecossistema" para baixar os exploits mais recentes.
  3. Auditoria: No módulo Orion, insira o IP alvo e defina o nível de scan.
  4. Análise: Verifique na Central de Inteligência se existem exploits compatíveis com as falhas encontradas.
  5. Defesa: Utilize o Aegis para gerar o relatório de correção.

Uso Indevido e Crimes Cibernéticos

O uso deste software em redes de terceiros sem autorização expressa constitui crime previsto na Lei nº 12.737/2012 (Lei Carolina Dieckmann), especificamente o Artigo 154-A: "Invadir dispositivo informático alheio...".

Pena: Detenção de 1 a 4 anos e multa.

🛡️ Conscientização e LGPD

A Lei Geral de Proteção de Dados (Lei nº 13.709/2018) regula o tratamento de dados pessoais. Ao utilizar o CÉREBRO-V3, o usuário deve estar ciente:

  • Privacidade: Scans de rede podem capturar informações sensíveis (MAC addresses, Hostnames). O tratamento desses dados deve respeitar a finalidade legítima.
  • Responsabilidade: O operador da ferramenta é o Controlador de Dados e responde legalmente por qualquer vazamento ou uso ilícito das informações coletadas durante a auditoria.
  • Ética: A ferramenta deve ser usada para fortalecer a segurança de dados, nunca para comprometê-la.
